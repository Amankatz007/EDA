# EDA

1) Standard Deviation = how far the point lies from mean

SD = √(Σ(x - μ)² / N)

Σ means "sum of"
x is each value in the data set
μ is the mean of the data set
N is the number of data points in the population (N-1 for Sample)
=================================================================

2) Z Score = how many standard deviations a data point is from the mean

z = (x - μ) / σ

x is each value in the data set
μ is the mean of the data set,
σ is the standard deviation of the data set

=================================================================

3) Chi-square Test = Comparision or relationship between Catogorical varaibles (Ex : Gender vs Hair Type(short, medium,long))

=================================================================

4) ANOVA Test = Comparision or relationship between atleast 1 Catogorical varaibles and other continuous variables (Ex : Gender vs Income)
